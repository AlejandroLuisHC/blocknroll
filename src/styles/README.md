# Estilos de Block n’ Roll

`index.css` carga la base y los estilos por sección. La base define la paleta, la tipografía, el ancho de lectura, los enlaces y el foco. Cada sección define su propia composición y sus puntos de adaptación.

La marca y las firmas fijas usan Feast of Flesh. Los titulares traducibles usan Barlow Condensed Black Italic, con letras deportivas y compactas y acentos completos para español y catalán; el texto y los controles usan Barlow. Todas las fuentes se sirven desde el proyecto. La paleta combina ciruela, naranja, lavanda y superficies claras. Los estilos de foco se adaptan a las superficies oscuras y el desplazamiento respeta la preferencia de movimiento reducido. Los tokens y sus usos están documentados en `DESIGN.md`.
