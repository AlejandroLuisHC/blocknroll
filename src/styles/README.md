# Estilos de Block n’ Roll

`index.css` carga la base y los estilos por sección. La base define la paleta, la tipografía, el ancho de lectura, los enlaces y el foco. Cada sección define su propia composición y sus puntos de adaptación.

La marca usa Feast of Flesh, servida desde el proyecto. El resto usa la tipografía de sistema. La paleta toma el amarillo de la pieza de captación y el violeta, crema y tinta del horario y de las piezas de competición. Los estilos de foco se adaptan a las superficies oscuras y el desplazamiento respeta la preferencia de movimiento reducido.
